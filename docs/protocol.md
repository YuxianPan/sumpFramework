# 协议契约

> **读者**：要写一个服务、或判断某个改动是否合规的人 ｜ **读完能做**：按契约收发消息、划清服务边界 ｜ **状态**：有效（信封 `v: 1`）

规则在这里，具体字段形状以 [`protocol/`](../protocol) 的载荷类型为准。

## 1. 独立性

1. **独立进程**：可单独启动 / 停止 / 重启；除「设置中心地址」这一条引导配置外，不依赖任何其他服务正在运行。
2. **独立存储**：只读写自己的库与目录，**不得**访问别人的。派生数据（缓存 / 索引 / 向量）必须可丢弃、可重建——**权威数据只有一份**，在它的归属服务里。
3. **只经网络访问**：按地址点对点直连，不经过任何中转。
4. **语言自由**：任何语言都可实现。`protocol/` 与 `service/` 是 Go 侧的参考实现，不是准入条件。

## 2. 信封

```jsonc
{
  "v": 1,                 // 协议版本
  "id": "01J...",         // 消息 id（请求 ↔ 响应配对）
  "trace": "01J...",      // 链路 id（同一条请求全链共享）
  "boss": "qq",           // 本跳「面向谁工作」（结果归属；逐跳自定、不可丢失）
  "type": "jump",         // 消息类型
  "from": "qq",
  "to": "reasoner",
  "payload": { }          // 该动作的数据（嵌套值，不是字节块）
}
```

- 传输：WebSocket；编码：MessagePack（二进制帧）。
- 访问模型：默认短连接、用完即走；只有需要响应的一跳才等。
- 可选字段为空时**不出现**（omitempty），解析端必须容忍缺键。

## 3. 消息类型

| type | 方向 | 语义 |
| --- | --- | --- |
| `register` | 服务 → 设置中心 | 注册（附名片）；**响应里带全量名册** |
| `response` | 任何请求的回复 | `{ok, data, error}`，按 `id` 配对 |
| `roster` | 设置中心 → 各服务 | 名册推送（事件） |
| `heartbeat` | 服务 → 设置中心 | 报活 / 告别（`status: "bye"`） |
| `jump` | 任何服务 → 任何服务 | **唯一的「访问」动作**；目标可以是自己 |
| `settings` | 设置中心 → 各服务 | 设置下发结果（事件） |

## 4. 动作

- 服务自定义动作在服务内唯一即可（`to` 已指明服务）；命名小写 + 下划线。
- **动作只增不改**：已有动作的语义与载荷字段只做加法，删改 = 破坏性变更。
- **未知字段必须忽略**（不得因多字段报错）；**未知动作必须回 `{ok:false, error}`**，不得静默丢弃。

### 链机制保留动作

`user_message`（链入口）/ `step`（自跳）/ `deliver`（终点直达 boss）/
`recall` `resume` `store`（记忆往返）/ `save` `fetch`（资产链）/ `report_result`（异步补报）。

这些是**协议级词汇**：即便某个服务提供了同名动作，也**不作为上层 agent 的工具暴露**。

## 5. 名片：`provides` 与 `settings`

```jsonc
{
  "name": "echo",
  "addr": "ws://127.0.0.1:9101/ws",
  "description": "把收到的文本加上前缀返回",
  "provides": [
    { "action": "echo", "input": "{text}", "output": "{text}",
      "tool": true,       // 暴露给上层 agent（默认 false）
      "async": false }    // 受理即回执（默认 false）
  ],
  "settings": [
    { "key": "prefix", "default": "echo: ", "label": "回声前缀", "kind": "text" },
    { "key": "token", "secret": true },
    { "key": "addr", "default": "127.0.0.1:9101", "readonly": true }
  ],
  "heartbeat_ms": 15000
}
```

- `provides[].input/output` 是**给人看的宽松描述**，不是 JSON Schema。
- **暴露必须显式**：`tool: true` 才给上层 agent 看。管理 / 调试类动作默认不要暴露。
- 名册里的名片**不含 settings**（设置声明只对中心可见）；要看某服务有哪些设置项，走 `list_settings`。

## 6. 三类设置项

| 类型 | 值存在哪 | 谁校验 |
| --- | --- | --- |
| **普通**（`default`） | 设置中心（`data/settings.json`） | 服务自己 |
| **秘密**（`secret: true`） | **服务自己**（`data/<名>-secret.json`，目录 0700 / 文件 0600 / 原子替换） | 服务自己 |
| **只读**（`readonly: true`） | 启动参数 | 不可改，改要重启 |

- 生效值 = **覆盖值 ?? 服务声明的预设值**。
- 下发：注册后中心异步全量对齐 + 变更单键下发；**受理回执只表示「已落盘受理」**，送达结果以 `settings` 事件回传。
- 秘密项**不进中心**：中心不落盘、不回显，只在提交那一次转发给服务。一句话：**谁消费谁持有**。
- 服务侧的值自己变了，用 `report_setting` 报事实；中心不改自己的覆盖值，只记「服务侧实际值」。

## 7. 异步：受理即回执

```jsonc
// 调用方 → 服务
{ "action": "run", "input": { "command": "ls -la" } }
// 服务 → 调用方（只表示已受理）
{ "ok": true, "data": { "item_id": "01J…", "phase": "queued" } }
// 之后每条进展都是独立的一跳
{ "action": "report_result", "input": { "item_id": "01J…", "phase": "done", "final": true, "text": "…" } }
```

- 受理回执不等执行；补报各自独立一跳；调用方离线 = 补报发不出去（服务只记日志，不排队）。
- 对不上 `item_id` 的补报**忽略即可**，不是错误。
- **零阻塞**：等待不该跨服务传递。阻塞只允许发生在相邻边界的直接应答内，且必有超时。

## 8. 链规则

- **boss 不可丢**：入口服务必须把 boss 设成**自己**，否则结果回不来。
- **deliver**：链终点判定结束后**直达 boss**，不沿链逆向回传。
- **trace**：全链共享，用于调试与审计。
- **发出即完**：一步 = 收到 → 处理 → 发出下一跳 → 结束。
- **失败**：拨号失败（消息可证明未送达）可安全重试；送达后的失败不重试（可能已被处理）。

## 9. 兼容与命名

- 类型 / 动作 / 载荷字段 / 服务名 / 设置键：**只增不改**；改名 = 破坏性变更。
- 命名：类型 = 裸名词；动作 = 小写下划线、动词_名词；字段 = snake_case（可选即省略）；服务名 = 小写短名；设置键 = `<域>.<名>`。
- `id` 用 26 字符 ULID 形态（时间有序）；**不能超过 2^53** 的数值不要放进跨语言字段（JSON 到 JS 会被抹平）。
